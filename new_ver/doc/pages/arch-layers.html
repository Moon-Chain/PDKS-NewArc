Katman Mimarisi

PDKS, katmanlı mimari (Layered Architecture) ile tasarlanmıştır. Her katman belirli bir sorumluluğu üstlenir; bir katmanın görevi bittikten sonra işi bir üst/alt katmana devredilir.

Bir HTTP isteği soldan sağa akar: Tarayıcı → server.ts → Middleware → Route → Service → Repository → PostgreSQL. Olaylar (izin onayı, bildirim) ise Service katmanından ayrı bir EventEmitter kanalıyla alt sistemlere (SSE, Push, Bildirim DB) dağıtılır.

Soldan sağa: HTTP isteğinin izlediği yol.
Aşağıya: EventEmitter üzerinden giden gerçek zamanlı bildirim akışı.
Kartları sürükleyebilir, fare tekerleğiyle zum yapabilirsiniz. ↺ başlangıç konumuna sıfırlar, ⛶ tam ekrana alır.

Katman Sorumlulukları

KatmanDosya/KlasörSorumluluğuNe Yapamaz?
Route routes/v1/ HTTP isteği al, doğrula, servise ilet, yanıtı döndür. Veritabanına doğrudan bağlanamaz.
Service services/ İş mantığını çalıştır (bakiye hesapla, QR doğrula, olay yayınla). HTTP req/res nesnelerini göremez.
Repository repositories/ SQL sorguları çalıştır, sonuçları döndür. İş mantığı taşıyamaz; sadece veri al/ver.
Middleware middleware/ Her istekte çalış; JWT doğrula, rol kontrol, body doğrula. İş mantığı kararı veremez.
EventEmitter events/ Sistem olaylarını yayınla ve dinle; SSE + Push + DB bildirimini tetikle. Route veya HTTP akışını bilemez.
