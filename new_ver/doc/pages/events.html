Gerçek Zamanlı (SSE)

Temel URL: /api/v1/events — Auth gereklidir.

PDKS, Server-Sent Events (SSE) teknolojisiyle gerçek zamanlı güncellemeler sağlar. Sayfa yenilemeye gerek kalmadan; devam kayıtları ve bildirimler ekranda anında güncellenir.

SSE — yalnızca sunucudan tarayıcıya veri gider. Basit, HTTP üzerinde çalışır, otomatik yeniden bağlanır.
WebSocket — çift yönlü; hem sunucu hem istemci mesaj gönderebilir. Karmaşık chat uygulamaları için daha uygundur.
PDKS için SSE yeterlidir: tarayıcının sunucuya anlık mesaj göndermesine gerek yoktur.

Bağlantı Kurma

Tarayıcı tarafında EventSource API'si ile bağlantı kurulur:

// SSE bağlantısı aç const source = new EventSource('/api/v1/events', { withCredentials: true // httpOnly cookie için zorunlu }); // Bağlantı başarıyla kurulunca source.addEventListener('connected', (e) => { const data = JSON.parse(e.data); console.log('Bağlandı — Kullanıcı:', data.userId, '— Rol:', data.role); }); // Devam kaydı geldiğinde (giriş/çıkış) source.addEventListener('attendance', (e) => { const log = JSON.parse(e.data); console.log(`${log.user_name} ${log.type === 'in' ? 'girdi' : 'çıktı'}`); }); // Yeni bildirim geldiğinde source.addEventListener('notification', (e) => { const notif = JSON.parse(e.data); console.log('Yeni bildirim:', notif.title); }); // Bağlantı kopunca (EventSource otomatik yeniden bağlanır) source.onerror = () => { console.log('Bağlantı koptu, yeniden deneniyor...'); };

Olay Türleri

Olay AdıNe Zaman Tetiklenir?Taşınan VeriKim Alır?
connected İstemci SSE bağlantısı açtığında anında gönderilir. { userId, role } Yalnızca bağlanan kullanıcı.
attendance Herhangi bir giriş/çıkış kaydı oluşturulduğunda. Tam devam log nesnesi (kullanıcı adı, tür, zaman damgası). Admin/müdür tüm şirketin kayıtlarını alır. Personel yalnızca kendi kaydını alır.
notification Kullanıcıya yönelik yeni bildirim oluşturulduğunda. Tam bildirim nesnesi (başlık, mesaj, tür, link). Yalnızca hedef kullanıcı.
:heartbeat Her 25 saniyede bir. Veri yok — sadece bağlantıyı canlı tutar. Tüm bağlı istemciler.
Bazı proxy, CDN veya load balancer katmanları çok uzun süre sessiz kalan bağlantıları kapatır. Her 25 saniyede gönderilen :heartbeat comment'i bu kesmeyi engeller. Tarayıcı tarafında görünmez; hiçbir event listener'ı tetiklemez.
