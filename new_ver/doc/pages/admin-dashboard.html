Admin Dashboard

GET /api/v1/admin/dashboard — dashboard:view yetkisi gereklidir (admin ve mudur).

Dashboard endpoint'i, admin panelinin ana sayfasını doldurmak için tasarlanmış birleşik bir veri kaynağıdır. Tek bir API çağrısıyla bugünkü devam durumu, bekleyen onaylar, yaklaşan tatiller ve personel dağılımı alınır. Tüm veriler o günün anlık durumunu yansıtır; başka şirketlerin verisini içermez.

Admin paneli açıldığında 5-6 ayrı API çağrısı yapmak yerine tek bir çağrıyla tüm widget verileri alınır. Bu yaklaşım ağ gecikmesini azaltır ve sayfa yükleme süresini kısaltır.
