DOM Yapısı

Bu sayfa; kullanıcı SPA'sının (index.html) ve admin panelinin (admin/index.html) DOM ağacını, JavaScript yüklenmeden önce ve sonraki halini, sayfa geçişlerinde DOM'da neler değiştiğini ve BasePage yaşam döngüsünü detaylandırır.

Mavi — HTML elementi  |  Sarı — attribute  |  Yeşil — değer / koşul  |  Açık mavi — fonksiyon çağrısı  |  Gri — yorum

1 — Statik DOM (JS yüklenmeden önce)

Sunucu public/index.html'yi gönderdiğinde, JavaScript henüz çalışmamıştır. DOM bu noktada yalnızca iskelet yapısından oluşur; tüm dinamik bölgeler boştur. 

<html>
│
├─ <head>
│    ├─ <meta charset="UTF-8">
│    ├─ <meta name="viewport" content="width=device-width, initial-scale=1.0">
│    ├─ <link rel="stylesheet" href="css/components.css">  render-blocking
│    ├─ <link rel="stylesheet" href="css/style.css">      render-blocking
│    ├─ <link rel="manifest"    href="manifest.json">     PWA meta
│    └─ <meta name="theme-color">
│
└─ <body>
     │
     ├─ <div id="header-container"></div>    ← BOŞTUR; TopBar buraya gelecek
     ├─ <div id="app"></div>                   ← BOŞTUR; sayfalar buraya gelecek
     ├─ <div id="nav-container"></div>       ← BOŞTUR; BottomNav buraya gelecek
     └─ <script src="js/app.js"></script>     ← JS yüklenince her şey canlanır

3 — Sayfa Geçişi (router.navigate)

Kullanıcı alt menüden İzinler'e tıkladığında DOM'da neler olduğunu adım adım görebilirsiniz. #app dışında hiçbir şey değişmez. 

Kullanıcı BottomNav'da "/leaves" linkine tıkladı
│
├─ router.navigate('/leaves')  çağrıldı
│    ├─ history.pushState(null, '', '/leaves')  → URL değişti, sayfa yenilenmedi
│    └─ router._render('/leaves')  çağrıldı
│
├─ ── Mevcut sayfa temizlendi ─────────────────────────────────────
│    ├─ this.current?.destroy()  (HomePage örneği)
│    │    ├─ BasePage.destroy():
│    │    ├─   _listeners dizisindeki tüm event listener'lar kaldırıldı
│    │    └─ container.innerHTML = ''  → <div id="app"> boşaldı
│    │
│    └─ container.classList.add('page-enter')  → CSS fade-in animasyonu başladı
│         └─ 200ms sonra: classList.remove('page-enter')
│
├─ ── Yeni sayfa chunk'ı yüklendi ─────────────────────────────────
│    ├─ routes['/leaves']()  → import('./pages/LeavesPage.js')
│    │    ├─ [ilk kez]  → js/chunks/leaves-[hash].js ağdan indirildi
│    │    └─ [sonraki kez]  → SW CacheFirst → önbellekten anında döndü
│    └─ PageClass = LeavesPage  (class referansı alındı)
│
├─ new LeavesPage(container)  → constructor çalıştı
│    └─ this.container = container  (BasePage'den)
│
├─ await page.render()  → async, API verisi bekleniyor
│    ├─ api.get('/api/v1/leaves')  → izin listesi alındı
│    ├─ this.container.innerHTML = html
│    │    └─ <div id="app"> şimdi şunu içeriyor:
│    │         <div class="leaves-page">
│    │              ├─ <div class="leaves-header">...
│    │              ├─ <button id="btn-new-leave">İzin Talep Et</button>
│    │              └─ <ul class="leave-list">...
│    └─ Event listener'lar bağlandı (BasePage.on() ile)
│         ├─ #btn-new-leave  → 'click' → modal açılır
│         └─ ... diğer dinleyiciler
│
├─ currentNav.setActive('/leaves')
│    └─ .bottom-nav a[href="/leaves"]  → class="active" eklendi
│
└─ ✓ LeavesPage DOM'da, önceki sayfanın hiçbir kalıntısı yok
router._render() her sayfa geçişinde önce this.current.destroy() çağırır. Bu metod tüm event listener'ları tek tek kaldırır ve container'ı boşaltır. Sayfalara eklenen dinleyicileri mutlaka BasePage.on() üzerinden bağlamalısınız; aksi hâlde bellek sızıntısı oluşur.

5 — BasePage Yaşam Döngüsü

Tüm sayfalar BasePage'i miras alır. Bir sayfanın tam yaşam döngüsü şöyledir: 

Router yeni bir sayfa render etmeye karar verdi
│
├─ 1. new XxxPage(container)  → constructor
│       └─ this.container = container   (BasePage kurucusundan)
│          Henüz DOM'a hiçbir şey yazılmadı
│
├─ 2. await page.render()  → async, override edilmiş
│       ├─ API'den veri çekildi
│       ├─ this.container.innerHTML = html  → DOM güncellendi
│       ├─ this.on('#btn', 'click', handler)  → dinleyici kaydedildi
│       │    └─ BasePage._listeners[] dizisine eklendi
│       └─ Sayfa ekranda görünür
│
├─ 3. ── Sayfa aktif ─ kullanıcı etkileşimde ──────────────────────
│       ├─ Tıklama, scroll, form submit → handler'lar çalışır
│       └─ SSE event → EventBus üzerinden sayfa güncellenir
│
└─ 4. page.destroy()  → router yeni sayfaya geçmeden önce çağırır
        ├─ _listeners dizisindeki her entry için:
        │    └─ el.removeEventListener(event, handler)
        ├─ _listeners = []  → dizi temizlendi
        └─ container.innerHTML = ''  → DOM temizlendi
             Bellek sızıntısı yok — garbage collector devreye girer
TopBar ve BottomNav, BasePage'den değil BaseComponent'ten türer ve router._render() tarafından asla yeniden oluşturulmaz. Yalnızca state.watch('user', ...) tetiklendiğinde — yani oturum açılıp kapandığında — yeniden mount edilirler.
