Sınıf Hiyerarşisi

Bu sayfa; backend ve frontend'deki tüm sınıfların kalıtım ağacını, hangi sınıfın ne zaman ve nerede örneklendiğini (instantiate), hangi metodların override edildiğini ve constructor'dan itibaren yürütme sırasını detaylı olarak gösterir.

Pembe/Kalın — sınıf adı  |  Gri/İtalik — abstract (örneklenemez)  |  Mavi — metod  |  Mor — özellik/alan  |  Gri/italik — yorum

1 — Backend: Repository Hiyerarşisi

Tüm repository'ler BaseRepository'den türer. Base sınıf; SQL injection önleme, findById, create, update, delete yardımcılarını sağlar. Somut sınıflar yalnızca domain'e özgü sorgular ekler. 

abstract BaseRepository  ← core/BaseRepository.ts
│   findById(id)             SELECT ... WHERE id=$1 AND company_id=$2
│   findAll(where?, limit?)  SELECT ... WHERE [conditions] LIMIT [n]
│   create(data)             INSERT ... RETURNING *
│   update(id, data)         UPDATE ... SET col=$n WHERE id=$1
│   delete(id)              DELETE / soft-delete (deleted_at)
│   buildWhere(conditions)   WhereCondition → parametre güvenli SQL parçası
│
├─ UserRepository          repositories/UserRepository.ts

├─ AttendanceRepository    repositories/AttendanceRepository.ts

│
├─ LeaveRepository         repositories/LeaveRepository.ts

2 — Backend: Service Hiyerarşisi

Servisler iş mantığını kapsar. BaseService, yetki kontrolü (assertAdmin, assertSelfOrAdmin) ve sayfalama yardımcılarını sağlar. 

abstract BaseService  ← core/BaseService.ts
│   assertAdmin(user)           role !== 'admin' → AppError(403)
│   assertAdminOrMudur(user)    role ∉ ['admin','mudur'] → AppError(403)
│   assertSelfOrAdmin(user, id) user.id !== id AND role !== 'admin' → AppError(403)
│   paginate(query, page, limit) LIMIT/OFFSET hesabı
│
├─ AuthService         services/AuthService.ts
│    login(email, pwd)           bcrypt.compare → jwt.sign → audit log
│    logout(jti)                 JTI kara listesine ekle
│    changePassword(id, old, new)
│    → UserRepository  bağımlılık
│
├─ UserService         services/UserService.ts
│    create(data, actorId)        assertAdmin + bcrypt hash + create
│    update(id, data, actor)      assertSelfOrAdmin + update
│    delete(id, actor)           assertAdmin + soft-delete
│    → UserRepository, AuditRepository
│
├─ AttendanceService   services/AttendanceService.ts
│    checkIn(data)               QR doğrula → cooldown → INSERT → emit
│    manualRecord(data)          assertAdmin → doğrudan kayıt
│    → AttendanceRepository, SettingsRepository, emitter
│
├─ LeaveService        services/LeaveService.ts
│    create(data)                iş günü say → bakiye kontrol → INSERT → emit
│    approve(id, actor)          assertAdminOrMudur → update → emit → audit
│    reject(id, actor)
│    cancel(id, actor)
│    → LeaveRepository, HolidayRepository, emitter, AuditRepository
│
├─ OvertimeService     services/OvertimeService.ts
│    create(data)
│    approve/reject/cancel(id, actor)
│    → OvertimeRepository, emitter, AuditRepository
│
├─ NotificationService services/NotificationService.ts
│    notify({userId, title, message, type})
│    │    ├─ NotificationRepository.create()  → DB'ye kayıt
│    │    ├─ SSE Manager → bağlı client'a anlık gönder

│    → NotificationRepository, sseClients, web-push
│
├─ SettingsService     services/SettingsService.ts
│    get(companyId)
│    update(companyId, data, actor)  assertAdmin
│    → SettingsRepository
│
├─ ExcelService        services/ExcelService.ts

3 — Frontend: Page Hiyerarşisi

Tüm kullanıcı sayfaları BasePage'den türer. render() abstract'tır — her sayfa kendi HTML'ini üretmek ve event listener'larını bağlamak zorundadır. 

abstract BasePage  ← public/ts/core/BasePage.ts
│   container: HTMLElement
│   _listeners: ListenerEntry[]  kayıtlı tüm event dinleyiciler
│   abstract render(): Promise<void>
│   on(selector, event, handler)  dinleyici ekle + _listeners'a kaydet
│   $(selector)                   container.querySelector()
│   $$(selector)                  container.querySelectorAll()
│   destroy()                     tüm dinleyiciler kaldır + container temizle
│
├─ LoginPage         pages/LoginPage.ts
│    render()  → form HTML + submit handler
│    handleSubmit()  → api.post + state.set + router.navigate
│
├─ HomePage          pages/HomePage.ts
│    render()  → api.get('/attendance/today') + status kartı
│    openQRScanner()  → QRScanner component başlatır
│
├─ LeavesPage        pages/LeavesPage.ts
│    render()  → izin listesi + bakiye
│    openNewLeaveModal()  → Modal component
│    submitLeave(data)  → api.post + liste güncelleme
│
├─ ApprovalsPage     pages/ApprovalsPage.ts
│    render()  → bekleyen izin + mesai listesi
│    approve(id, type)  → api.post
│    reject(id, type, reason)
│
├─ UsersPage         pages/UsersPage.ts
│    render()  → kullanıcı kartları
│    openUserDetail(id)
│
├─ ProfilePage       pages/ProfilePage.ts
│    render()  → profil formu + avatar yükleme
│    uploadAvatar(file)  → api.upload
│
├─ MovementsPage     pages/MovementsPage.ts
│    render()  → hareketler tablosu + tarih filtresi
│
├─ QRDisplayPage     pages/QRDisplayPage.ts
│    render()  → api.get('/auth/me') + QR kodu oluştur (qrcode lib)
│
├─ SettingsPage      pages/SettingsPage.ts
│    render()  → uygulama ayarları formu
│
├─ NotificationsPage pages/NotificationsPage.ts
│    render()  → bildirim listesi + okundu işareti
│
└─ PlaceholderPage   pages/PlaceholderPage.ts
     render()  → "Yakında" mesajı

4 — Frontend: Component Hiyerarşisi

Sayfaların dışında kalan kalıcı bileşenler (TopBar, BottomNav) ve yardımcı bileşenler (Modal, Toast) BaseComponent'ten türer. Bunlar router._render() tarafından asla yeniden oluşturulmaz. 

abstract BaseComponent  ← public/ts/core/BaseComponent.ts
│   abstract mount(container: HTMLElement): void
│   destroy()  dinleyicileri kaldır
│
├─ TopBar             components/TopBar.ts
│    mount(el)  → header HTML + dropdown + bildirim butonu
│    state.watch('profile') değiştiğinde renderTopBar() ile yeniden mount edilir
│
├─ BottomNav          components/BottomNav.ts
│    mount(el)   → alt navigasyon linkleri (role'e göre farklı)
│    setActive(path)  → aktif linki vurgular
│    admin veya müdür rolünde ekstra "Onaylar" sekmesi görünür
│
├─ Modal              components/Modal.ts
│    open(title, content, onConfirm)
│    close()  → ESC + dışına tıkla ile de kapanır
│    Sayfalar modal'ı doğrudan örnekler: new Modal().open(...)
│
├─ Toast              components/Toast.ts
│    show(message, type, duration)  → 3000ms sonra otomatik kapanır
│    Toast.show() static çağrılabilir — container body'ye eklenir
│
├─ QRScanner          components/QRScanner.ts
│    open(onSuccess)  → kamera izni iste + video stream + jsQR döngüsü
│    close()          → stream durdur, DOM temizle
│
├─ NotificationPanel  components/NotificationPanel.ts
│    open()   → bildirim listesi yükle, panel göster
│    close()  → panel gizle
│    TopBar bell butonuna tıklandığında açılır
│
├─ Skeleton           components/Skeleton.ts
│    render(count, type)  → shimmer placeholder'lar
│    API yanıtı beklenirken sayfanın içerik alanına eklenir
│
└─ StatusIndicator    components/StatusIndicator.ts
     update(isOnline)  → online/offline durumu gösterir
     window 'online'/'offline' event'ini dinler

6 — BasePage Constructor → destroy() Sırası

new LeavesPage(container)  çağrıldı
│
├─ 1. BasePage.constructor(container) çalıştı
│    ├─ this.container = container
│    └─ this._listeners = []   boş dinleyici listesi
│
├─ 2. LeavesPage.constructor(container) çalıştı (varsa)
│    └─ super(container) mutlaka çağrılır
│
├─ 3. await page.render() çağrıldı
│    ├─ API verisi alındı
│    ├─ this.container.innerHTML = html
│    └─ this.on('#btn-new', 'click', handler)
│         └─ el.addEventListener('click', handler)
│            this._listeners.push({ el, 'click', handler })
│
├─ 4. Kullanıcı sayfayla etkileşime girdi...
│       handler'lar tetiklendi, API çağrıları yapıldı
│
└─ 5. Router yeni sayfaya geçiyor → page.destroy() çağrıldı
     ├─ _listeners dizisindeki her {el, event, handler} için:
     │    └─ el.removeEventListener(event, handler)
     ├─ this._listeners = []
     └─ this.container.innerHTML = ''
          LeavesPage örneği garbage collect edilebilir
          ✓ Bellek sızıntısı yok
