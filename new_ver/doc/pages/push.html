Push Bildirimler

Temel URL: /api/v1/push

Push bildirimler, Web Push Protokolü ve VAPID anahtarları kullanılarak çalışır. Kullanıcı uygulamayı kapatmış olsa bile tarayıcı bildirimi alır ve ekranda gösterir.

In-App Bildirim — uygulama açıkken SSE üzerinden gelir, navbar'daki sayaç güncellenir.
Push Bildirimi — uygulama kapalıyken bile gelir; işletim sisteminin bildirim alanında görünür (Chrome, Edge, Firefox destekler).

Push Bildirimi Nasıl Çalışır?

Service Worker kaydından önce sunucudan VAPID public key alınır: GET /api/v1/push/vapid-key

pushManager.subscribe() çağrısıyla tarayıcı, VAPID public key'i kullanarak push servisiyle (FCM / autopush vb.) bir abonelik oluşturur. Abonelik nesnesi endpoint URL'si ve şifreleme anahtarlarını içerir.

POST /api/v1/push/subscribe ile abonelik nesnesi sunucuya gönderilir. Sunucu bunu kullanıcının push_subscription alanına JSONB olarak kaydeder.

İzin onayı, red gibi olaylarda sunucu web-push kütüphanesiyle VAPID özel anahtarıyla imzalanmış bildirim gönderir. Push servisi tarayıcıya iletir; Service Worker bildirimi ekranda gösterir.

Endpoint'ler

VAPID public key herkese açık olabilir; gizlilik gerektirmez. Service Worker kayıt sürecinin en başında, kullanıcı henüz giriş yapmadan önce de bu key'e ihtiyaç duyulabilir. // Tam uygulama örneği — Service Worker kayıt ve abonelik async function enablePushNotifications() { // 1. Service Worker'ı kaydet const registration = await navigator.serviceWorker.register('/sw.js'); // 2. VAPID public key al const { key } = await fetch('/api/v1/push/vapid-key').then(r => r.json()); // 3. Push aboneliği oluştur const subscription = await registration.pushManager.subscribe({ userVisibleOnly: true, applicationServerKey: key // VAPID public key }); // 4. Aboneliği sunucuya kaydet await fetch('/api/v1/push/subscribe', { method: 'POST', credentials: 'include', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ subscription }) }); console.log('Push bildirimler etkinleştirildi.'); } Kullanıcının push_subscription alanı NULL yapılır. Bir sonraki olay tetiklendiğinde bu kullanıcıya push bildirimi gönderilmez; yalnızca in-app bildirim oluşturulur.
