Kullanıcılar

Temel URL: /api/v1/users

Kullanıcılar modülü, şirket çalışanlarının oluşturulmasını, güncellenmesini ve yönetilmesini sağlar. Her kullanıcı bir şirkete (company_id) bağlıdır ve yalnızca kendi şirketinin verilerine erişebilir.

user:view — liste ve profil görüntüleme (admin, mudur, takım lideri)
user:manage — oluşturma, güncelleme, silme, şifre sıfırlama (admin, mudur)

personel rolündeki kullanıcılar bu endpoint'lere erişemez. Kendi profillerini yalnızca GET /api/v1/auth/me ile görebilirler.

Kullanıcı Veri Modeli

Veritabanındaki users tablosunun her alanı ve ne anlama geldiği:

AlanTipAçıklama
id UUID Birincil anahtar. Otomatik üretilir, değiştirilemez.
personnel_id string Sicil numarası. Aynı şirkette iki kullanıcı aynı sicile sahip olamaz.
name string Ad soyad.
title string Unvan veya departman (örn. "Yazılım Geliştirici").
email string E-posta adresi (opsiyonel).
role enum admin mudur takim_lideri personel
manager_id UUID Bu kullanıcının bağlı olduğu yöneticinin ID'si. Bağlı olmayabilir (NULL).
leave_balance integer Kalan yıllık izin günü sayısı. Varsayılan: 14. İzin onaylanınca düşülür.
start_date date İşe başlama tarihi (YYYY-MM-DD).
can_remote_check_in boolean Uzaktan giriş izni. true ise bu kullanıcı ofise gitmeden giriş yapabilir.
avatar_path string Profil fotoğrafının sunucudaki yolu. NULL olabilir.
is_deleted boolean Soft delete bayrağı. true ise kullanıcı devre dışıdır.

Endpoint'ler

Evet. is_deleted = true yapılan kullanıcı veritabanında korunur. Gerekirse admin bir PATCH isteğiyle is_deleted: false göndererek kullanıcıyı yeniden etkinleştirebilir. Önemli: Şifre sıfırlandığında kullanıcının aktif oturumu kapatılır; bir sonraki girişte yeni şifre kullanması gerekir. İstek Content-Type: multipart/form-data formatında gönderilmelidir. Dosyalar /uploads/avatars/{companyId}/ dizinine kaydedilir. Kullanıcı kendi avatarını yükleyebilir; admin/mudur başka kullanıcılar adına da yükleyebilir.
