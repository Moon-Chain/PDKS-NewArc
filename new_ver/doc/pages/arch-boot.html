Boot Sekansı

Bu sayfa; sunucu (server.ts), kullanıcı uygulaması (app.ts) ve admin paneli (app-admin.ts) başladığında hangi adımın hangi sırayla çalıştığını, hangi modülün hangisini tetiklediğini detaylı olarak gösterir. Her dal gerçek kaynak kodundan türetilmiştir.

Sarı — başlangıç noktası / tetikleyici  |  Mavi — fonksiyon / metod çağrısı  |  Turuncu — event  |  Mor — veri  |  Yeşil — koşul/dal  |  Kırmızı — hata yolu

1 — Sunucu Boot Sekansı

tsx server.ts (geliştirme) veya node dist/server.js (production) komutu çalıştırıldığında Node.js modülleri import sırasına göre eş zamanlı olarak yüklenir; ardından uygulama kurulumu yukarıdan aşağı akar. 

$ tsx server.ts  ← geliştirme; production'da: node dist/server.js
│
├─ dotenv.config()
│    └─ .env dosyası okundu → process.env dolduruldu
│         ├─ PORT, DATABASE_URL, JWT_SECRET
│         └─ VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VAPID_EMAIL
│
├─ ── Modüller import sırasıyla yüklendi ──────────────────────────
│    ├─ core/Logger.ts  → Winston singleton oluşturuldu
│    │    ├─ Console transport: geliştirmede renkli format
│    │    └─ File transport: logs/app-YYYY-MM-DD.log (günlük rotasyon)
│    ├─ middleware/requestId.ts  → UUID middleware factory hazır
│    ├─ middleware/rateLimit.ts  → globalLimiter oluşturuldu (100 istek/15 dk)
│    ├─ core/AppError.ts  → özel hata sınıfı tanımlandı
│    ├─ db/connection.ts  → pg.Pool oluşturuldu
│    │    ├─ max: 10 bağlantı, idleTimeoutMillis: 30000
│    │    └─ İlk gerçek DB bağlantısı henüz açılmadı — ilk sorguyla açılır (lazy)
│    ├─ routes/v1/auth.ts  → AuthService + UserRepository import edildi
│    ├─ routes/v1/attendance.ts  → AttendanceService + AttendanceRepository
│    ├─ routes/v1/events.ts  → sseClients Map oluşturuldu (SSE bağlantıları tutulur)
│    ├─ routes/v1/users.ts  → UserService + UserRepository
│    ├─ routes/v1/leaves.ts  → LeaveService + LeaveRepository
│    ├─ routes/v1/overtime.ts  → OvertimeService + OvertimeRepository
│    ├─ routes/v1/notifications.ts  → NotificationService
│    ├─ routes/v1/push.ts  → web-push kütüphanesi + VAPID ayarları
│    ├─ routes/v1/holidays.ts  → HolidayRepository
│    ├─ routes/v1/reports.ts  → ExcelService
│    ├─ routes/v1/admin/index.ts  → AdminService + AuditRepository
│    └─ events/setup.ts  → Event dinleyicileri kayıt edildi
│         ├─ emitter.on('error')  → hata log'lanır, sunucu çökmez
│         ├─ emitter.on('leave:requested')  → yöneticiye bildirim gönderilir
│         ├─ emitter.on('leave:approved')  → personele bildirim gönderilir
│         ├─ emitter.on('leave:rejected')  → personele bildirim gönderilir
│         ├─ emitter.on('overtime:requested')  → yöneticiye bildirim gönderilir
│         ├─ emitter.on('overtime:approved')  → personele bildirim gönderilir
│         └─ emitter.on('overtime:rejected')  → personele bildirim gönderilir
│
├─ const app = express()  → Express uygulaması oluşturuldu
│
├─ ── Middleware zinciri kuruldu ──────────────────────────────────
│    ├─ app.set('trust proxy', 1)  → Cloudflare / reverse proxy IP güveni
│    ├─ app.use(helmet({...}))  → HTTP güvenlik başlıkları
│    │    ├─ Content-Security-Policy: self + Alpine.js CDN + Cloudflare analytics
│    │    ├─ X-Content-Type-Options: nosniff
│    │    ├─ X-Frame-Options: DENY
│    │    └─ Strict-Transport-Security (HSTS)
│    ├─ app.use(cors({...}))  → CORS politikası
│    │    ├─ localhost:*  → izinli
│    │    ├─ ngrok.io, trycloudflare.com  → izinli
│    │    └─ ALLOWED_ORIGINS env  → virgülle ayrılmış ek domainler → izinli
│    ├─ app.use(requestId)  → her isteğe UUID atanır
│    ├─ app.use(globalLimiter)  → rate limiting
│    ├─ app.use(cookieParser())  → cookie'ler parse edilir
│    └─ app.use(express.json({ limit: '1mb' }))  → JSON body parse
│
├─ ── Statik dosya sunumları ──────────────────────────────────────
│    ├─ /public  → CSS, JS bundle'lar, ikonlar, sw.js
│    └─ /uploads  → kullanıcı avatar'ları
│
├─ ── API Route'ları bağlandı ─────────────────────────────────────
│    ├─ /api/v1/auth         → authRoute
│    ├─ /api/v1/attendance   → attendanceRoute
│    ├─ /api/v1/events       → eventsRoute (SSE akışı)
│    ├─ /api/v1/users        → usersRoute
│    ├─ /api/v1/settings     → settingsRoute
│    ├─ /api/v1/leaves       → leavesRoute
│    ├─ /api/v1/overtime     → overtimeRoute
│    ├─ /api/v1/notifications → notificationsRoute
│    ├─ /api/v1/push         → pushRoute
│    ├─ /api/v1/holidays     → holidaysRoute
│    ├─ /api/v1/reports      → reportsRoute
│    └─ /api/v1/admin/*      → adminRoute (dashboard, audit)
│
├─ ── SPA Fallback'ler ────────────────────────────────────────────
│    ├─ /admin/*  → public/admin/index.html  (Admin SPA)
│    └─ /*       → public/index.html         (Kullanıcı SPA)
│
├─ ── Global hata işleyici ────────────────────────────────────────
│    ├─ AppError instance  → HTTP kodu + mesaj client'a döndürülür
│    └─ Beklenmedik hata   → 500 döner, logger.error() çağrılır
│
└─ app.listen(PORT)  → ✓ Sunucu http://localhost:PORT üzerinde çalışıyor
     └─ logger.info('Sunucu başladı')

2 — Kullanıcı Uygulaması Boot Sekansı

Tarayıcı ilk kez (veya yeniden) /home gibi bir URL açtığında, sunucu SPA shell'ini (index.html) döndürür. Ardından js/app.js yüklenerek uygulamayı başlatır. 

Tarayıcı http://localhost:3000/home adresine gitti
│
├─ ── Sunucu tarafı ───────────────────────────────────────────────
│    └─ server.ts catch-all /*  → public/index.html gönderildi
│
├─ ── Tarayıcı HTML parse ─────────────────────────────────────────
│    ├─ <head> işlendi
│    │    ├─ css/components.css yüklendi  (render-blocking)
│    │    ├─ css/style.css yüklendi  (CSS değişkenleri, dark theme)
│    │    └─ manifest.json  → PWA meta bilgileri alındı
│    └─ <body> işlendi
│         ├─ <div id="header-container">  boş — TopBar buraya gelecek
│         ├─ <div id="app">              boş — sayfalar buraya gelecek
│         └─ <div id="nav-container">    boş — BottomNav buraya gelecek
│
├─ js/app.js yüklendi & çalıştı
│    │
│    ├─ ── Modül seviyesi (init'ten önce, senkron) ──────────────────
│    ├─ Alpine.start()  → MutationObserver ile x-data elementlerini izler
│    ├─ navigator.serviceWorker.register('/sw.js')
│    │    └─ sw.js install edildi (ilk ziyarette) / aktif edildi
│    │         ├─ CSS/JS/İkon'lar: CacheFirst stratejisi
│    │         └─ /api/*: NetworkFirst stratejisi
│    ├─ initOfflineBanner()  → online/offline olayları dinlenmeye başladı
│    ├─ listenSWSync(sendOfflineItem)  → SW 'sync' event'i dinleniyor
│    ├─ window.addEventListener('online', syncQueue)
│    │
│    └─ init()  çağrıldı  (async)
│         │
│         ├─ api.get('/api/v1/auth/me')  → oturum kontrolü
│         │    ├─ [200 - profil alındı]
│         │    │    ├─ state.set('user',    {id, role, company_id})
│         │    │    └─ state.set('profile', profile)
│         │    └─ [401 / ağ hatası]  → null döndü, user state boş kaldı
│         │
│         ├─ new Router(routes, app)  → router oluşturuldu
│         │    └─ window.addEventListener('popstate', ...)  → geri/ileri butonu dinleniyor
│         │
│         ├─ state.watch('user', callback)  → user her değiştiğinde tetiklenir
│         │    ├─ renderTopBar()  → #header-container güncellenir
│         │    ├─ renderNav()     → #nav-container güncellenir
│         │    ├─ [user var]   → eventStream.connect()  SSE bağlantısı açılır
│         │    └─ [user yok]  → eventStream.disconnect()
│         │
│         ├─ state.watch('profile', renderTopBar)  → avatar/isim değişiminde güncellenir
│         │
│         ├─ renderTopBar()  → ilk render
│         │    ├─ [user var]   → new TopBar(profile).mount(headerEl)
│         │    └─ [user yok]  → header boş kalır
│         │
│         ├─ renderNav()  → ilk render
│         │    ├─ [user var]   → new BottomNav(role).mount(container)
│         │    └─ [user yok]  → nav gösterilmez
│         │
│         ├─ [user var]  → eventStream.connect()
│         │    └─ new EventSource('/api/v1/events')  → SSE bağlantısı açıldı
│         │
│         ├─ router.navigate override edildi
│         │    └─ orijinal navigate + currentNav.setActive(path)
│         │
│         └─ router._render(location.pathname)  → ilk sayfa render
│              ├─ [user yok && path !== '/login']  → navigate('/login')
│              ├─ [user var && path === '/login']   → navigate('/home')
│              └─ [geçerli sayfa]
│                   ├─ container.classList.add('page-enter')  → CSS transition
│                   ├─ routes[path]()  → lazy import()
│                   │    └─ js/chunks/home-[hash].js  indirildi & parse edildi
│                   ├─ new HomePage(container)  → constructor çalıştı
│                   └─ await page.render()  → ✓ İlk sayfa DOM'da

3 — Admin Paneli Boot Sekansı

Admin paneline (/admin/*) erişildiğinde sunucu ayrı bir SPA shell'i (admin/index.html) döndürür. Bu shell, kullanıcı uygulamasından bağımsız bir bundle (app-admin.js) yükler. 

Tarayıcı http://localhost:3000/admin adresine gitti
│
├─ server.ts: /admin/*  → public/admin/index.html gönderildi
│
├─ admin/js/app-admin.js yüklendi & çalıştı
│    │
│    ├─ applyAppearance()  → tweaks/appearance.ts
│    │    └─ localStorage'dan tema ayarları okundu, CSS değişkenleri uygulandı
│    │
│    ├─ routes nesnesi oluşturuldu  (moduleRegistry'den)
│    │    ├─ ADMIN_MODULES listesi tarandı
│    │    │    ├─ /admin            → DashboardPage loader
│    │    │    ├─ /admin/movements  → MovementsPage loader
│    │    │    ├─ /admin/approvals  → ApprovalsPage loader
│    │    │    ├─ /admin/users      → UsersPage loader
│    │    │    ├─ /admin/leaves     → LeavesPage loader
│    │    │    ├─ /admin/overtime   → OvertimePage loader
│    │    │    ├─ /admin/holidays   → HolidaysPage loader
│    │    │    ├─ /admin/notifications → NotificationsPage loader
│    │    │    ├─ /admin/settings   → SettingsPage loader
│    │    │    ├─ /admin/reports    → ReportsPage loader
│    │    │    └─ /admin/audit      → AuditLogPage loader
│    │    └─ ADMIN_EXTRA_ROUTES de eklendi
│    │
│    └─ init()  çağrıldı  (async)
│         │
│         ├─ api.get('/api/v1/auth/me')  → oturum + rol kontrolü
│         │    ├─ [hata / null]              → window.location.href = '/login'
│         │    └─ [role !== 'admin']        → window.location.href = '/'
│         │
│         ├─ state.set('user', ...)
│         ├─ state.set('profile', ...)
│         ├─ eventStream.connect()  → SSE bağlantısı (admin bildirimler)
│         │
│         ├─ new AdminLayout(app, location.pathname)
│         │    ├─ Sidebar render edildi (modül linkleri + kullanıcı bilgisi)
│         │    ├─ AdminTopBar render edildi
│         │    ├─ AdminNotifPanel hazırlandı (gizli, bell ile açılır)
│         │    └─ layout.contentEl  → sayfalar buraya mount edilecek
│         │
│         ├─ new Router(routes, layout.contentEl)  → router oluşturuldu
│         │
│         ├─ router.navigate override edildi
│         │    └─ orijinal navigate + layout.setActivePage(path)
│         │
│         └─ router._render(location.pathname)  → ilk admin sayfası render
│              └─ DashboardPage yüklendi → ✓ Admin paneli hazır
Her sayfa (HomePage, LeavesPage, vb.) ayrı bir esbuild chunk'ıdır. router._render() çağrısına kadar hiçbir sayfa kodu indirilmez. Bu sayede ilk yükleme yalnızca app.js boyutuna bağlıdır (~60-80 KB gzip).
